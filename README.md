# Travelgram

Projeto desenvolvido durante os estudos na **Rocketseat**, com o objetivo de praticar a construção de uma interface de perfil de viagens utilizando **HTML e CSS**.

O Travelgram simula o perfil de uma rede social voltada para viagens, reunindo informações do usuário, navegação e uma galeria de fotos.

> **Observação:** nomes, imagens e informações exibidas na interface fazem parte do conteúdo demonstrativo do projeto.

## 🎯 Objetivo

Praticar a construção e estilização de uma página web a partir de um layout proposto, trabalhando principalmente organização dos elementos, distribuição do conteúdo e estruturação dos estilos.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📚 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos como:

- HTML semântico
- Organização e estilização de elementos
- Layout e alinhamento de conteúdo
- Navegação com listas e links
- Utilização de imagens e ícones
- Variáveis CSS
- Tipografia com Google Fonts
- Organização modular dos estilos

## 🧩 Estrutura da página

A interface é composta por:

- Barra de navegação
- Informações do perfil
- Dados sobre localização, viagens e fotos
- Galeria de imagens
- Rodapé

## 📁 Organização do CSS

Os estilos foram separados de acordo com diferentes partes da interface:

- `global.css` — configurações e estilos globais
- `nav.css` — barra de navegação
- `header.css` — informações do perfil
- `main.css` — galeria de imagens
- `footer.css` — rodapé
- `style.css` — arquivo principal de estilos

Essa separação foi utilizada para praticar uma organização mais modular do CSS.

## 📖 Contexto

Este projeto faz parte da minha trajetória de estudos em desenvolvimento web na **Rocketseat**.

Durante sua construção, pratiquei a transformação de uma referência visual em uma página estruturada com HTML e estilizada com CSS, além de trabalhar uma melhor organização dos arquivos de estilo.
